# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private
vulnerability reporting (the "Report a vulnerability" button on the Security tab of this
repository) and include the FoliaBoard version, server software and a description of the impact.

You will get a first response within a week. Fixes for confirmed issues are released as a
patch version and listed in `CHANGELOG.md`.

## Supported versions

Only the latest release line receives fixes.
